# KELDIN TV — Android TV downloads

Official public release channel for the **independent KELDIN TV Android TV application**.

**Installation using Downloader** (available only after the first signed APK release):

`https://github.com/keldin94/keldin-tv-releases/releases/latest/download/KeldinTV.apk`

Open the Downloader app on your Android TV, paste the URL and select **Install**. Grant unknown-app installation permission if prompted. Once the app is installed, it checks this repository for newer releases and can download/install them from **Settings → Check for updates**, without Downloader.

## Current release status

No public production-signed release has been published yet. Do not distribute the older debug APK as an official release: it uses a different signing certificate and cannot upgrade in place.

Signed releases are built from the separate **private** `keldin94/keldin-tv` source repository and published here with a SHA-256 checksum. The original `keldin94/keldin-iptv` project remains independent.

KELDIN TV is a media player only and does not provide IPTV channels, playlists, or unauthorized streaming services.
