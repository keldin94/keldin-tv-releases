# KELDIN TV — signed Android TV releases

This repository hosts **APK releases only** for the independent KELDIN TV Android TV application.

- Source code is maintained in the private `keldin94/keldin-tv` repository.
- Android TVs check the **latest GitHub Release** here, then download `KeldinTV.apk` and `KeldinTV.apk.sha256`.
- The Android update flow additionally checks the installed package ID and signing certificate. A system installation confirmation can still be required.
- **No official APK has been published yet.** Do not install or distribute unsigned or unverified builds.
- This is separate from the earlier Keldin IPTV app and does not update or replace it.

The app is a player only: no IPTV streams or subscriptions are provided.
